# 베트남어 스터디 (v1)

동기끼리 매일 15분. **단어 10개 + 문형 틀 2개 + 대화 미션 1개.**
신규는 다 같이, 복습은 각자.

## 지금 상태
**4주치 커리큘럼 완성** — 단어 200개 / 문형 틀 40개 / 대화 미션 21개

| 구간 | 내용 |
|---|---|
| 준비 (Day 0) | 문자와 성조 6개 |
| 1주차 (Day 1~5) | 인사·호칭 / 이름 / 나라 / 직업 / 안부 |
| 2주차 (Day 6~10) | 숫자 / 수량 / 시간 / 요일 / 하루 일과 |
| 3주차 (Day 11~15) | 작업 지시 / 속도·완료 / 품질·불량 / 수량 보고 / 위치 |
| 4주차 (Day 16~20) | 안전·보호구 / 착용·응급 / 교대 / 설비·공구 / 못 알아들었을 때 |

- 서버 없음. 진도는 브라우저에 저장
- 모든 예문은 **그날까지 배운 단어만** 사용 (미학습 낱말 0건, 자동 검증)
- Day 11부터는 **새 문법을 얹지 않는다** — 1~10주차 틀에 현장 어휘만 갈아끼운다

## 실행
```
python3 -m http.server 5177
```
브라우저에서 http://localhost:5177 열기.

## 배포 (동기들에게 링크 주기)
GitHub에 올리고 Settings → Pages → Branch: main / root.
폰에서 열고 "홈 화면에 추가" 하면 앱처럼 보인다.

## 콘텐츠 늘리기
1. `data/days.json` 에 Day 항목 추가 (형식은 기존 Day 참고)
2. `python3 tools/gen_audio.py` — 새로 추가된 것만 음성을 만든다 (기존 파일은 건너뜀)

`edge-tts` 필요: `pip install edge-tts` (무료·계정 불필요)

## 구조
```
index.html / app.js / style.css   화면과 로직 (447줄)
data/days.json                    커리큘럼 전부
data/audio_index.json             텍스트 → 음성 파일명 대조표 (자동 생성)
audio/{f,m}/{n,slow}/*.mp3        음성 (자동 생성)
tools/gen_audio.py                음성 생성기
docs/plan.md                      기획서
docs/research-textbooks.md        교재·교육기관 조사
```

## 설계 원칙 (근거는 docs/ 참고)
- **복습이 본체다.** 신규 10개보다 매일 돌아오는 복습 큐가 중요
- **한글 발음은 숨겨둔다.** 탭해야 보이고, 시작 14일 뒤 사라짐 (성조를 담지 못하므로)
- **틀에 단어를 갈아끼운다.** 10단어 × 2틀 = 하루 20문장
- **대화는 정보차 과제로.** "자유롭게 대화해봐"는 초급자끼리 아무것도 못 만든다
