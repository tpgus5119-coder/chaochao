# 베트남어 스터디

### 👉 https://tpgus5119-coder.github.io/vietnamese-study/

폰에서 열고 **"홈 화면에 추가"** 를 누르면 앱처럼 씁니다.
아이폰: 공유 버튼 → 홈 화면에 추가 · 안드로이드: 메뉴 → 홈 화면에 추가


동기끼리 매일 15분. **단어 10개 + 문형 틀 2개 + 대화 미션 1개.**
신규는 다 같이, 복습은 각자.

## 지금 상태
**일상 기초 한 트랙.** 완전 초보(베트남어를 전혀 모르는 사람) 기준.

| | |
|---|---|
| 준비 3일 | 글자·모음 / 성조 6개 / 헷갈리는 자음 |
| 20일 | 단어 **100개** (하루 5개), **대화 20개** (하루 주고받는 2문장) |
| 하루 분량 | 단어 5 + 대화 1개 — 약 10분 |
| 성조 | 글자에서 **자동으로** 뽑아 모든 단어·문장에 표시 (`tools/tone.py`) |
| 음성 | MP3 774개 / 12MB (남·여 × 보통·느린) |

```
준비   P1 글자와 모음 · P2 성조 6개 · P3 헷갈리는 자음
1~5    인사 / 이름 / 반갑습니다 / 감사·대답 / 안부
6~10   나라 / 사는 곳 / 못 알아들었을 때 / 알아요·몰라요 / 작별
11~15  개수 / 숫자 4~8 / 나이 / 시간 / 하루 일과
16~20  요일 / 음식 / 값 / 도움 요청 / 약속
```

### 하루 한 장이 이렇게 생겼다
```
단어 5장 → 대화 1장

  [ 오늘의 대화 · 이름 묻고 답하기 ]
       ▶ 대화 전체 듣기
 ┌────────────────────────────┐
 │ Ⓐ  🔊 🐢                    │
 │ Tên của anh là gì?         │
 │ 형 이름이 뭐예요?            │
 │ ＼huyền  ／sắc  —ngang     │ ← 성조 자동 표시
 │ [Tên|이름][của|~의][là|이다]│ ← 단어별 풀이
 │ 한글 발음 보기               │
 └────────────────────────────┘
 ┌────────────────────────────┐
 │ Ⓑ  🔊 🐢                    │
 │ Tên tôi là Nam.            │
 │ 제 이름은 남이에요.           │
 └────────────────────────────┘
```

- 대화 문장은 **그날 배운 단어로만** 만든다 — 자동 검증, 위반 0건
- 서버 없음. 진도는 브라우저에 저장 (백업 버튼 있음)

### 나중에 (선배 자료 받은 뒤)
하루 **2세트**로 늘린다 — 일상 기초 + 직업(생산제조).
직업 트랙용 현장 어휘 100개는 `data/보관/v2-현장어휘-보관.json` 에 넣어뒀다.

## 실행
```
python3 -m http.server 5177
```
브라우저에서 http://localhost:5177 열기.

## 배포
```
python3 tools/stamp.py          # ← 반드시 먼저. 안 하면 옛 화면이 계속 보인다
git add -A && git commit -m "..." && git push
```
`main` 에 push 하면 GitHub Pages 가 1분 안에 반영한다.

> **왜 stamp.py 가 필요한가**: GitHub Pages 는 CSS/JS 에 `max-age=600` 을 붙여
> 브라우저가 10분간 옛 파일을 쓴다. `stamp.py` 가 `style.css?v=<내용해시>` 처럼
> 주소를 바꿔서 강제로 다시 받게 한다. 내용이 안 바뀌면 해시도 그대로라 헛되이 안 받는다.

## 콘텐츠 늘리기
커리큘럼 원본은 `tools/build_*.py` 다. `data/days.json` 을 직접 고치지 말 것.

```
python3 tools/build_days.py       # 준비 3일 + 성조 드릴
python3 tools/build_daily.py      # Day 1~10
python3 tools/build_daily2.py     # Day 11~20
python3 tools/assemble.py          # 검증만
python3 tools/assemble.py --write  # 검증 통과 시 days.json 기록
python3 tools/gen_audio.py         # 새로 늘어난 것만 음성 생성
python3 tools/stamp.py             # 판번호 (배포 전 필수)
```

`assemble.py` 가 막아주는 것: 단어 중복, **아직 안 배운 낱말이 문장에 섞이는 것**.
둘 중 하나라도 걸리면 days.json 을 쓰지 않는다.

`edge-tts` 필요: `pip install edge-tts` (무료·계정 불필요)

## 설계 원칙 (근거는 docs/ 참고)
- **복습이 본체다.** 신규 10개보다 매일 돌아오는 복습 큐가 중요
- **한글 발음은 숨겨둔다.** 탭해야 보이고, 시작 14일 뒤 사라짐 (성조를 담지 못하므로)
- **통문장 앞에 단어별 풀이를 놓는다.** 초보에게 문장은 뜻 없는 소리 덩어리다
- **문장마다 갈아끼운 변형 2개.** 문장 4개 = 실제로는 12개를 본다
- **대화는 정보차 과제로.** "자유롭게 대화해봐"는 초급자끼리 아무것도 못 만든다
