## 지금 상태
**완전 초보(베트남어를 전혀 모르는 사람) 기준으로 다시 짬.**

| | |
|---|---|
| 준비 3일 | 글자·모음 / 성조 6개 / 헷갈리는 자음 |
| 20일 | 단어 **200개**, 문장 **80개**(+변형 160) |
| 하루 분량 | 단어 10 + **문장 4** — 일상 2 · 현장 2 |
| 음성 | MP3 **1,466개 / 19MB** (남·여 × 보통·느린) |

```
준비    P1 글자와 모음 · P2 성조 6개 · P3 헷갈리는 자음
1주차   인사·호칭 / 이름·소속 / 나라·하는 일 / 못 알아들었을 때 / 안부·작별
2주차   숫자 / 개수 세기 / 시간 / 요일 / 하루 일과
3주차   지시·부탁 / 다 됐어요·빨리 / 품질·불량 / 수량 보고 / 위치
4주차   안전·보호구 / 착용·응급 / 교대·근무 / 설비·공구 / 묻고 답하기
```

### 문장 하나가 화면에 나오는 방식
```
        [ 일상 — 완전 처음 ]
            Chào anh!
        🔊 듣기   🐢 느리게
      안녕하세요! (손위 남자에게)
     ┌───────┐ ┌───────┐
     │ Chào  │ │  anh  │      ← 단어별 풀이
     │ 안녕  │ │형·오빠│         (쌩초보에겐 통문장이 벽이다)
     └───────┘ └───────┘
         한글 발음 보기          ← 눌러야 열림, 14일 뒤 사라짐
   ── 이렇게도 말합니다 ──
      Chào chị!  🔊
      Chào em!   🔊             ← 단어만 갈아끼운 변형
```

- 서버 없음. 진도는 브라우저에 저장
- 모든 문장은 **그날까지 배운 단어만** 사용 — 자동 검증, 현재 위반 0건
- Day 11부터는 **새 문법을 얹지 않는다.** 배운 틀에 현장 어휘만 갈아끼운다

## 콘텐츠 늘리기
커리큘럼 원본은 `tools/build_*.py` 다. `data/days.json` 을 직접 고치지 말 것.

```
python3 tools/build_days.py && python3 tools/build_p2.py && python3 tools/build_p3.py
python3 tools/assemble.py            # 검증만 (중복·미학습 낱말 확인)
python3 tools/assemble.py --write     # 검증 통과 시 days.json 기록
python3 tools/gen_audio.py            # 새로 늘어난 것만 음성 생성
```

`assemble.py` 가 막아주는 것: 단어 중복, **아직 안 배운 낱말이 문장에 섞이는 것**.
둘 중 하나라도 걸리면 days.json 을 쓰지 않는다.

`edge-tts` 필요: `pip install edge-tts` (무료·계정 불필요)

## 설계 원칙 (근거는 docs/ 참고)
- **복습이 본체다.** 신규 10개보다 매일 돌아오는 복습 큐가 중요
- **한글 발음은 숨겨둔다.** 탭해야 보이고, 시작 14일 뒤 사라짐 (성조를 담지 못하므로)
- **통문장 앞에 단어별 풀이를 놓는다.** 초보에게 문장은 뜻 없는 소리 덩어리다
- **문장마다 갈아끼운 변형 2개.** 문장 4개 = 실제로는 12개를 본다
- **대화는 정보차 과제로.** "자유롭게 대화해봐"는 초급자끼리 아무것도 못 만든다
