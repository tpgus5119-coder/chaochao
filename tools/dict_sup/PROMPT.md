# 사전 [보충] 뜻 1차 판정 (2026-10-01)

우리 사전 뜻은 위키낱말사전을 그대로 옮긴 것이라 **흔히 쓰는 뜻이 빠진** 낱말이 있다(nhạc nhẹ 가 '소규모 악단'뿐 — 흔한 뜻 '경음악'이 없음).
입력 `sup_NN.json`: 낱말마다 `n` · `w` 낱말 · `dict` 지금 사전 뜻(앞 글자는 품사: 명 동 형 부 대 …, '-'는 품사 없음) ·
`lesson` 앱 수업 자료의 뜻(사람이 검수) · `from` 그 수업 · `krdict` 국립국어원 한국어기초사전에서 이 낱말을 대역으로 단 한국어 낱말 · `ex` 수업 예문.

출력 `sup_NN.ko.tsv`: 낱말 하나 = 한 줄, 입력 차례 그대로 빠짐없이 — `n<탭>판정<탭>보충 뜻<탭>품사<탭>까닭`

판정은 넷 중 하나:
- `같음` — lesson·krdict 의 말이 사전 뜻 가운데 하나와 **같은 뜻**(다르게 쓴 말·비슷한 말·말맛 차이 포함: 체력↔기력, 만족한↔만족하다, 백팩↔배낭, 상쾌하다↔편안한). 보충 뜻·품사·까닭 칸은 비움. **대부분은 이것이다.**
- `보충` — 사전 어느 뜻에도 없는 **다른 뜻**이고, 베트남어에서 실제로 흔히 그 뜻으로 쓴다고 **확실할 때만**. 예: nhạc nhẹ → 경음악 · xỏ → (신발을) 신다 · lẫn → (A lẫn B) A와 B 모두.
  보충 뜻은 짧은 한국어(2~15자, 필요하면 괄호로 쓰임새), 품사는 명 동 형 부 대 수 조 감 구 중 하나, 까닭은 40자 안(왜 다른 뜻인지).
  krdict 말이 드문 비슷한 말(깡충·핫바지·여쭈다)이면 보충이 아니라 같음. 한 낱말에 보충 뜻이 둘이면 ' · ' 로 이어 한 칸에.
- `틀림` — lesson 뜻이 이 낱말의 뜻이 **아니다**(다른 낱말과 헷갈림: thiếp 초대장 → 그건 thiệp, chương 메달 → 그건 huy chương). 보충 뜻 칸에 맞는 뜻(알면), 까닭에 근거.
- `모름` — 판단 근거가 모자람. 까닭에 한 줄.

확실하지 않으면 `같음` 또는 `모름`. 지어내지 않는다. 한국어 칸에 로마자는 까닭 칸에서만(베트남어 낱말 인용).
검사: `python3 tools/dict_sup/chk.py sup_NN` — 문제 0 이어야 끝.
