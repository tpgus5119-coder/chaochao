# 고른 예문 독립 확인 (2026-10-01)
입력 `vf_NN.json`: `n` · `w` 낱말 · `ko` **수업에서 가르치는 뜻** · `vi` 예문(교재 원문 또는 사전 예문) · `tr` 붙인 한국어 번역 · `from`.
출력 `sh_NN.b.tsv`: 줄마다 `n<탭>Y 또는 N<탭>고친 번역(필요할 때만)<탭>까닭(N 일 때 필수, 40자 안)` — 입력 차례 그대로 빠짐없이.
- `Y`: 예문에서 그 낱말이 **수업 뜻 그대로** 쓰였고, 문장이 자연스러운 베트남어(OCR로 글자·성조가 틀린 낱말 없음)이며, 혼자 읽어도 뜻이 통한다.
  번역이 틀렸거나 어색하면 3번째 칸에 고친 번역(로마자 없이, 80자 안). 맞으면 비움.
- `N`: 다른 뜻으로 쓰임 · 다른 낱말의 조각 · OCR 오류 의심 · 문장이 잘림/지시문/빈칸 · 뜻이 안 통함.
확실하지 않으면 N. 베트남어 문장은 고치지 않는다.
검사: `python3 tools/ex_source/chk_vf.py vf_NN` — 문제 0 이어야 끝.
