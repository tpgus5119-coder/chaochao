# 수업 카드 예문 고르기 — 교재 원문 → 사전 예문 → 그대로 (2026-10-01)

대표님 원칙: **1순위 메인 교재 문장, 2순위 사전 문장, 둘 다 쓸 만한 게 없으면 지금 예문(만든 예문) 그대로.**
입력 `sh_NN.json`: 낱말마다 `n` · `part` 갈래 · `w` 낱말 · `ko` **수업에서 가르치는 뜻** · `cur` 지금 예문(대부분 AI가 만든 것) ·
`T` 교재 원문 후보(T1~T4, `ok`=1 은 쪽 이미지로 확인된 문장, `where` 권·과·쪽) · `W` 사전(위키) 예문 후보(W1~W2, 한국어 있음).
출력 `sh_NN.ko.tsv`: 낱말 하나 = 한 줄, 입력 차례 그대로 빠짐없이 — `n<탭>고른 것<탭>한국어 번역<탭>까닭`
- 고른 것: `T1`~`T4` · `W1`~`W2` · `0`(그대로).

고르는 법 (차례대로):
1. 후보 문장에서 그 낱말이 **수업 뜻(`ko`) 그대로** 쓰였나가 제일 중요하다. 다른 뜻(ba '아버지' 수업인데 문장은 숫자 3), 다른 낱말의 한 조각, 고유명사의 일부면 안 된다.
2. 그런 T 가 있으면 T 에서 고른다(`ok`=1 을 먼저, 그다음 짧고 뜻이 분명한 것). T 가 하나도 안 되면 W 에서. 둘 다 안 되면 `0`.
3. 예문으로 쓸 수 있는 문장이어야 한다: 혼자 읽어도 뜻이 통하는 온전한 문장이나 구. 빈칸·번호·보기·지시문·대화 이름표는 안 된다.
4. **OCR 오류 의심**(성조·글자가 이상한 낱말, 말이 안 되는 차례)이 보이면 그 후보는 고르지 않는다.
5. 한국어 번역: T 를 고르면 자연스러운 한국어로 새로 쓴다(80자 안, 로마자 없이, 이름은 한글로). W 를 고르면 주어진 한국어를 쓰되 틀렸으면 고친다. `0` 이면 번역 칸은 비운다.
6. 까닭: 40자 안. 0 이면 왜 안 되는지(뜻 다름·후보 없음·OCR 의심 등).

지어내지 않는다 — 후보 문장의 베트남어는 한 글자도 바꾸지 않는다.
