# 베→한 뜻 쓰기 규칙 (vw 시트)

입력: `vw_NN.json` — 항목마다 `n`(번호), `vi`(베트남어 낱말), `pos`(품사, 있으면), `defs`(베트남어 위키낱말사전 뜻풀이, `품사|뜻` 꼴), `hint`(국립국어원 한국어기초사전에서 이 낱말을 베트남어 대역으로 가진 한국어 표제어 — 참고용, 틀릴 수 있음).
출력: `vw_NN.ko.tsv` — 줄마다 `n<탭>vi<탭>한국어 뜻`. **번호 1부터 빠짐없이, 입력과 같은 차례로, 한 항목 = 한 줄.**

뜻 쓰는 법
- 한국어 뜻만. 베트남어·영어 낱말을 뜻 안에 쓰지 않는다 (괄호 안에도).
- 짧게: 뜻 하나에 2~12자. 뜻이 둘 이상이면 ` · `(가운뎃점, 양옆 띄움)로 잇고 흔한 뜻부터, 셋까지.
- 명사는 명사로, 동사는 '-다'로, 형용사는 '-하다/-다'로. 사전 뜻처럼 쓴다("먹다", "책상", "한가롭다").
- 뜻풀이의 딱지는 짧게 괄호로: (옛), (방언), (남부), (속어), (불교), (문학) 등. 없으면 안 쓴다.
- 고유명사(지명·인명·경전 이름)는 뜻에 그 종류를 넣는다: "중국 서북쪽의 관문(옛 지명)", "아미타경(불경)".
- 속담·관용구는 뜻을 한 줄로 풀어 쓴다(12자 넘어도 됨, 40자 이내).
- `hint`가 뜻풀이와 맞으면 그 한국어 낱말을 쓴다. 안 맞으면 무시한다. 지어내지 않는다.
- 뜻풀이가 너무 모자라 뜻을 알 수 없으면 `-` 한 글자만. (붙임말 조각, 뜻풀이가 "~의 옛 표기"뿐이고 그 낱말을 모르는 것 등)
- 뜻풀이가 "X의 다른 표기/옛 표기/방언"이고 X 를 안다면 X 의 뜻을 쓰고 딱지를 붙인다: "고수(방언)".

검사: `python3 tools/dict_vw/chk.py vw_NN` 가 번호·한글·길이를 본다. 문제 0 이어야 끝.
