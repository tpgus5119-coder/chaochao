# 사전 예문에 한국어 뜻 달기 (2026-10-01)

입력 `ex_NN.json`: 표제어마다 `n` 번호 · `w` 표제어 · `k` 우리 사전의 한국어 뜻(참고) · `x` 예문 목록(`i` 번호 · `vi` 베트남어 예문 · `en` 위키에 적힌 영어 뜻, 없으면 빈칸).
출력 `ex_NN.ko.tsv`: **예문 하나 = 한 줄** — `n<탭>i<탭>한국어 뜻`. 입력의 모든 예문을 차례 그대로, 빠짐없이.

- 베트남어 예문 `vi` 를 **자연스러운 한국어 한 문장**으로 옮긴다. 예문에 없는 말을 보태지 않는다. 표제어 `w` 가 그 예문에서 어떤 뜻으로 쓰였는지가 드러나게.
- `en` 이 있으면 그 뜻을 따른다(위키가 붙인 번역). 여러 갈래(" / ")면 가장 기본인 첫 뜻.
- 한국어만. 로마자·베트남어 글자를 쓰지 않는다. 사람·땅 이름은 한국어로 소리 나는 대로(Hà Nội 하노이, Giê-su 예수).
- 문장이 아니라 구(bánh quế giòn tan)면 구로 옮긴다("바삭바삭한 와플 과자").
- 옛 시·속담은 뜻이 통하게 옮긴다. 끝의 출처 표시 "(K)" "(Tục ngữ)" 같은 것은 옮기지 않는다.
- 이런 예문은 뜻 칸에 `x` 한 글자만: 문장이 중간에 잘렸거나 낱말이 빠져 말이 안 됨 · 베트남어가 아님 · 욕설·성적·차별 표현이 주된 내용 · 뜻을 정할 수 없음.

검사: `python3 tools/dict_ex/chk.py ex_NN` — 번호가 빠짐없이 차례대로인지, 한글인지, 로마자 없는지. 문제 0 이어야 끝.
