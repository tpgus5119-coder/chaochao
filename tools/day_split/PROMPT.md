# 일상 주제 나누기 — 낱말을 A·B 로

베트남어 학습 앱의 일상 단어 주제 'A와 B'(예: 인사와 자기소개)를 두 주제로 나눈다. 시트 `ds_N.json` 의 주제마다 A 이름·B 이름과 낱말 목록(베트남어·한국어 뜻)이 있다.

## 할 일
낱말 하나하나를 **A 또는 B** 중 더 잘 맞는 쪽으로 정한다. 한국어 뜻과 베트남어를 보고, 학습자가 그 주제 이름을 보고 기대할 낱말인지로 판단한다.
- 어느 쪽에도 딱 맞지 않으면(예: 인사와 자기소개의 anh·chị·em 같은 부르는 말) **그 낱말이 실제로 더 자주 쓰이는 장면** 쪽으로. 까닭에 그렇게 적는다.
- 한쪽에 몰아 넣지 말고 낱말마다 따로 판단한다. 결과로 한쪽이 아주 적어도 괜찮다.

## 출력
`ds_N.tsv` — 한 줄에 하나, 탭으로: `주제(원래 이름 그대로)⇥베트남어(그대로)⇥A 또는 B⇥까닭(한국어 짧게, 10~30자)`.
시트의 모든 낱말을 빠짐없이 한 번씩. 다 쓰면 `python3 tools/day_split/chk.py N` 이 '문제 0' 이 될 때까지 고친다.

## 지킬 것
- 시트·출력 파일 말고 프로젝트 파일은 건드리지 않는다. 임시 파일은 맡은 임시 폴더에만.
- 다른 ds_*.tsv 는 열지 않는다.
- 끝나면 주제마다 A 몇·B 몇과, 판단이 갈렸던 낱말 몇 개를 짧게 보고한다.
