# 뉴스클리핑봇 설치·운영 가이드 (가비아 윈도우 서버)

매일 저녁 8시(KST), 베트남·중국·인도네시아 경제 기사 3~5개를 골라
카카오톡 오픈채팅방 3곳에 자동 전송한다. 사람 손은 최초 세팅 1회뿐.

---

## 0. 큰 그림

```
Google 뉴스 RSS ─► 후보 수집 ─► 최근 21일 보낸 기사 제외 ─► Claude가 3~5개 선별
   └► 당일(24h) 우선, 3개 미만이면 이틀 전까지 확대
메시지 조립 ─► 카톡 PC 화면 자동화로 방 3곳에 전송 ─► '나와의 채팅'에 결과 보고
```

## 1. 가비아 서버 주문

가비아 → **g클라우드(클라우드 서버)** → 신규 서버.

| 항목 | 선택 |
|---|---|
| OS | Windows Server 2022 (한국어) |
| 사양 | 2 vCPU / 4 GB / SSD 50GB (제일 낮은 축이면 충분) |
| 요금제 | **월 정액** |
| 지역 | 국내 |
| 공인 IP | 1개 부여 |

주문하면 관리자 비밀번호와 공인 IP가 나온다. 예상 월 3~4만원.

## 2. 서버 최초 접속 (딱 한 번)

내 PC에서 **원격 데스크톱 연결**(mstsc) → 공인 IP 입력 → Administrator + 발급 비번.

## 3. 윈도우 기본 세팅

원격 접속한 서버 안에서:

1. **시간대**: 설정 → 시간 및 언어 → 시간대 **(UTC+09:00) 서울** 확인.
2. **절전 끄기**: 설정 → 전원 → 화면·절전 모두 **안 함**.
3. **자동 로그인**: `Win+R` → `netplwiz` → "사용자 이름과 암호를 입력해야…" 체크 해제 → 비번 입력.
   (재부팅되어도 바탕화면까지 자동으로 올라오게)
4. **자동 로그인 후 화면 잠김 방지**: `regedit` →
   `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon` 에
   문자열값 `DisableLockWorkstation` = `1` (없으면 만든다). 또는 그룹정책에서 잠금 비활성화.
   ※ RDP로 나갈 때는 창을 그냥 닫지 말고 **연결 끊기**로만 나온다(세션 유지).

## 4. 프로그램 설치

서버에서 Edge로:

1. **Python 3.12** (python.org) — 설치 시 "Add python.exe to PATH" 체크.
2. **카카오톡 PC** (kakaocorp.com) 설치.
3. 이 프로젝트 폴더를 서버 `C:\newsbot\` 에 복사 (GitHub에서 clone 하거나 압축 전달).
4. 명령 프롬프트(cmd):
   ```
   cd C:\newsbot
   python -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   ```

## 5. 카카오톡 로그인 (사람 손 필요 — 이때 1번뿐)

1. 카톡 PC 실행 → 대표님 계정 로그인 → **휴대폰으로 오는 인증 승인**.
2. 로그인 유지: 설정 → "PC에서 자동 로그인" 켜기.
3. 대상 **오픈채팅방 3개**에 입장해 둔다.
4. 카톡 설정 → 채팅 → **"Enter 키로 메시지 보내기" 켜짐** 확인 (기본값).
5. 방 이름 3개를 `bot\config.py` 의 `room` 값에, `나와의 채팅` 은 그대로 둔다.

## 6. API 키

Claude API 키 발급(console.anthropic.com) 후, 서버 시스템 환경변수에 등록:

```
setx ANTHROPIC_API_KEY "sk-ant-..." /M
```

결제수단 등록 필요. 사용량은 하루 1회라 월 몇백 원~2천 원.

## 7. 손으로 1회 테스트

```
cd C:\newsbot
.venv\Scripts\python bot\run.py --dry-run    (전송 안 하고 메시지만 출력 — 내용 확인)
.venv\Scripts\python bot\run.py               (실제 전송 — 방 3곳 + 나와의 채팅 확인)
```

카톡 창 위치/버전에 따라 `send_kakao.py` 의 방 여는 방식이 안 맞을 수 있다.
이때 화면을 보며 한 번만 조정하면 그 뒤로는 계속 된다.

## 8. 매일 자동 실행 등록

작업 스케줄러 → 작업 만들기:

- 트리거: 매일 **20:00**
- 동작: 프로그램 시작
  - 프로그램: `C:\newsbot\.venv\Scripts\python.exe`
  - 인수: `C:\newsbot\bot\run.py`
  - 시작 위치: `C:\newsbot`
- 조건: "AC 전원일 때만" 체크 해제
- 설정: "작업이 실패하면 다시 시작" → 5분 간격 3회

카톡 자동화는 화면이 살아 있어야 하므로 **"사용자가 로그온할 때만 실행"** 으로 둔다
(3번에서 자동 로그인 + 잠금 해제를 해놨으므로 재부팅돼도 유지된다).

## 9. 무인 유지 장치 (이미 코드/설정에 반영)

- 전송 실패 시 3초 뒤 1회 재시도 → 그래도 실패면 '나와의 채팅'에 오류 보고.
- 매일 결과 요약이 '나와의 채팅'에 오므로, 안 오면 그날 문제 있는 것.
- 가비아 콘솔에서 **매일 새벽 스냅샷** 예약 → 카톡 업데이트로 깨지면 복구 1번.
- 기사 중복: `bot\sent_history.json` 에 21일치 기록, 자동 정리.

## 10. 문제 생기면

| 증상 | 원인/조치 |
|---|---|
| 결과 보고가 안 옴 | 서버가 꺼졌거나 로그아웃됨 → 가비아 콘솔에서 재부팅 |
| "방 창을 찾지 못함" | 카톡 방 이름과 `config.py` 의 `room` 불일치, 또는 카톡 UI 변경 |
| 기사가 2개만 옴 | 그날 당일+전일 기준 맞는 기사가 실제로 부족 (정상 동작) |
| API 오류 | 키 만료 또는 잔액 소진 |
