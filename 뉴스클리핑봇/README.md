## 구성

| 파일 | 역할 |
|---|---|
| `bot/config.py`   | 주제·검색어·방 이름·개수 설정 |
| `bot/collect.py`  | Google 뉴스 RSS에서 당일 기사 후보 수집 (공식 RSS, 크롤링 차단 없음) |
| `bot/dedup.py`    | 최근 21일 보낸 기사 기록·중복 제외 |
| `bot/curate.py`   | Claude API로 '한국인 관점 경제기사' 3~5개 선정 + 한 줄 멘트 |
| `bot/compose.py`  | 카톡 메시지 문자열 조립 |
| `bot/send_kakao.py` | 카톡 PC 화면 자동화 전송 (윈도우 전용) |
| `bot/run.py`      | 위를 순서대로 실행 + 재시도 + 결과 보고 |

## 선정 기준 (curate.py 프롬프트)

- 당일 기사 우선, 3개 미만이면 이틀 전까지 확대
- 그 나라 '경제'만 (정치·사건사고·연예·스포츠 제외)
- 한국인에게 의미: 현지 진출 한국기업 / 거시지표(성장률·GDP·교역) / 시장·산업 전망
- 현지 관영매체 홍보성 국정기사 제외
- 같은 사안은 최신·구체적인 것 1건만
