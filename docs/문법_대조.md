# 교재 문법 ↔ 앱 문법(grammar.json) 대조 (2026-09-25, 지시 #5)

**질문:** 메인교재 각 과와 줌 수업에 문법이 있나? 앱에 이미 있는 문법과 겹치나?

## 결론 먼저
- **메인교재 1권**: 2~5과·7~11과에 "TÌM HIỂU NGỮ PHÁP"(문법 익히기) 상자가 있다 — 낱말 쓰임(đã·đang·rất·ạ·nhé…)을 베트남어·영어로 한 쌍씩 설명. 1과(발음)·6과·12과(복습)엔 문법 절이 없다.
- **메인교재 2권**: 1~5과·7~11과에 "NGỮ PHÁP" 절이 있고(번호 매긴 구문 47항목) 6과·12과(복습)엔 없다. 설명은 베트남어뿐.
- **줌 수업 10개**: 명시적 문법 제목이 있는 것은 5~10강 여섯 개(길 묻기·음료 주문·식당 질문·장보기 구조·색깔·이름/나이 묻기). 1~4강(글자·모음·자음·인칭대명사·숫자/돈)은 낱말·발음이 중심이고 문법 제목이 따로 없다.
- **앱 문법(grammar.json)**: 177점, 기초(10과)·중급1(10과)·중급2(10과). 원본은 NGUYỄN VIỆT HƯƠNG 세 권의 과별 문법이라 **메인교재와는 다른 책**이다. 그래서 **같은 항목이 겹치기도 하고 안 겹치기도 한다**(아래).
- 겹치는 것은 **합치지 않고 그대로 둔다** — 앱 문법은 다른 책의 설명이고 예문도 다르다. 겹침 표시(아래 표)를 앱에 붙이려면 대표님 결정이 필요하다.

## 방법과 한계 (다음 사람이 믿어도 되는 만큼)
- 2권: 쪽 OCR(`ocr2`) 에서 "NGỮ PHÁP" 뒤 번호 항목을 뽑고 항목 번호 연속성으로 빠진 것을 채웠다 — 각 과 마지막 번호와 맞춤.
- 1권: 상자 표제 규칙 추출이라 누락 가능. 겹침 판정은 앱 grammar.json 의 항목 제목(`t`)과 대조한 **제목 수준** 판정이다(예문·설명 내용까지 본 것은 아님).
- 이 표로 앱을 고친 것은 없다.
