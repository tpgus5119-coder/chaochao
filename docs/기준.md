- **관심사 점수 8점 미만은 안 싣는다** (2026-09-02에 5→8로 올림 — "5로 뒀더니 7점짜리

  비워 둔다 — **남는 자리를 다른 갈래로 몰지 않는다**(한쪽 주제 쏠림 방지, `card_pick.py`의
  미채택 로직에서 가져옴)
- 하루 갈래가 최소 5가지는 나와야 한다 — 한두 갈래로 쏠리면 경고만 하고 그대로 둔다

### 갈래는 이렇게 정한다 (2026-09-15 수정 — 실제 `fetch_news.py` 코드와 다르게 적혀 있었다)
1. **우리 낱말표(`CATS`)로 1차 분류** — 제목으로 한 번, 본문까지 받은 뒤 다시 한 번

## 4. 낱말 — 어떻게 검수하나

### 한 칸에 낱말 하나
- 잣대는 **길이가 아니라 사전에 한 표제어로 실리는가**
- `bảo hiểm y tế`(건강보험)는 네 음절이어도 한 낱말
- `màu đỏ`는 두 음절이어도 `màu`+`đỏ` 두 낱말
- 사전에 없으면 **쪼개 본다.** 조각이 모두 아는 낱말이면 조각을 따로 넣는다
- **다만 뜻이 부분의 합이 아니면 안 쪼갠다** — `xe đạp`(자전거)를 차+밟다로 쪼개면 자전거가 사라진다

### 검수 차례
1. **우리 사전** `data/_vi_words.json` (47,341 표제어) — 공짜·즉시
2. **위키낱말 실시간 조회** — 우리 사전에 없는 것만
3. **최종: 사전 뜻풀이 대조** — Qwen 에게 뜻풀이를 쥐여 주고 고르게 한다
4. **사람이 마지막 판정**

### 발음
`tools/vi_kr.py` 가 만든다. **AI 금지** — 같은 글자면 늘 같은 결과라야 검산이 된다.
받은 발음에 한글이 아닌 글자가 있으면 다시 만든다 (`học → [học]` 사고).

> **남부 목소리는 2026-09-09에 완전히 없앴다** (대표님 지시: "남부 소리 버튼과 코드와

### 검수 항목
| 무엇 | 어떻게 |
|---|---|
| 낱말마다 두 목소리가 다 있나 | 해시로 센다 |
| 두 목소리가 서로 다른가 | 파일 해시 비교 |
| **낱말을 제대로 말하나** | Whisper 받아쓰기 |

**받아쓰기는 두 음절 이상에서만 믿는다.** 한 음절은 0.3초라 못 알아듣는다
(실측: 두 음절 이상 0.74 · 한 음절 0.58).

### 재생 속도
파일은 한 벌. **기본 0.8배속 / 느리게 0.6배속**을 재생으로 조절한다(설정 「소리 속도」,
2026-09-09부터 — 예전엔 1배속/0.7배속이었는데 "빠르게 느껴진다"는 지적으로 낮췄다).
느린 파일을 따로 굽지 않는다 — 용량만 늘고, `playbackRate` 는 성조를 지켜 준다.
**주의**: `audio.playbackRate`는 반드시 `audio.src`를 정한 **다음**에 설정해야 한다 —
거꾸로 하면 새 src가 로드되며 브라우저가 배속을 조용히 1.0으로 되돌린다(2026-09-09에
이 순서가 뒤바뀌어 있어 0.8배속이 실제로는 전혀 안 먹히던 버그를 찾아 고쳤다).

## 6. 그림 — 어떻게 만들고 검수하나

| 무엇 | 도구 |
|---|---|
| 글감 | Qwen (`img_prompt_gen.py`) |
| 굽기 | **Draw Things** FLUX schnell **4단계** 512×512 |
| 붙이기 | `img_link.py` (같은 낱말·같은 뜻) |
| 검수 ① 뜻을 알려주나 | Qwen (`img_audit.py`) |
| 검수 ② 이상한 그림인가 | **Qwen3-VL 8B** 또는 사람 |

- **8단계로 굽지 않는다.** schnell 은 4단계용이라 시간만 두 배 든다
- **추상어는 "사실적 묘사 불가"로 자동 반려하지 않는다** (2026-09-15 수정 — 예전엔
  "그릴 수 없는 말엔 그림을 안 붙인다"였으나 근거 조사 결과 절반만 맞았다. 상징적·은유적
  이미지는 추상어 의미기억도 유의미하게 높이고 효과가 6개월 지속된다는 연구가 있음
  [Andrä et al. 2020, Farley et al. 2012] — 구체어는 "사실적 묘사", 추상어는 "상징적
  장면으로 뜻이 유추되는가"로 **다른 잣대**를 적용한다). 다만 붐비는·사라지다처럼 상징
  으로도 안 잡히는 말은 여전히 그림을 안 붙인다
- Qwen 판정만으로 떼지 않는다. **말끝이 움직씨·그림씨인 것만** 뗀다 (실측: 20%가 잘못 걸렸다)
- 그림 파일은 **지우지 않는다** — 판정이 틀리면 되붙인다

### 이미지 검수 체크리스트 (2026-09-15 근거 조사로 추가)
연구 근거: 이중부호화이론(Clark & Paivio 1991), Mayer의 멀티미디어학습이론(Mayer &
Fiorella 2014), 구체성효과(Farley et al. 2012), 그림의 과신 함정(Carpenter & Olson 2012)

1. **일관성** — 뜻과 무관한 장식·소품·인물이 있으면 반려 (효과크기 d=0.86)
2. **단서성** — 목표 개념이 화면에서 가장 눈에 띄는가 (효과크기 d=0.86)
3. **공간적 근접성** — 낱말 텍스트와 이미지가 붙어 있는가 (**효과크기 d=1.10, 다섯 항목
   중 가장 큼** — 레이아웃이 이미지 내용만큼 중요하다는 뜻)
4. **구체성 이원 판정** — 위 "추상어는 자동 반려하지 않는다" 참고
5. **과신 함정 체크** — 오답 후보와 같이 놓아도 이 그림이 정답 낱말을 실제로 변별해
   주는가(그림이 있으면 안다고 착각하는 걸 막는다)

## 8. Qwen 에게 일 시키는 법

### 네 관문 — 하나라도 걸리면 안 준다 (`tools/route.py`)
① 검산할 수 있나 · ② 틀리면 눈에 띄나 · ③ 지어낼 자리가 없나 · ④ 시간이 되나(1.2초/건)

### 묻는 법 넷
1. **만들게 하지 말고 고르게 한다** — "뜻이 뭐냐"(✗) → "이 뜻풀이 중 맞는 것"(○)
2. **근거를 적게 한다** — "어느 대목을 봤는지 적어라. 못 적으면 고치지 마라" (224→17)
3. **개수를 채우라고 하지 않는다** — "열 개뿐이면 열 개만" (안 그러면 255개를 지어낸다)
4. **받은 답은 규칙으로 다시 거른다** — 한글인가 · 12자 이내인가 · 지어낸 숫자인가

### 거르는 규칙도 한 번은 돌려본다
"베트남어 낱말이 한국어 기사 본문에 있어야 한다"고 걸렀다가 **전부 죽었다** (2026-09-02).

### 모델은 한 번에 하나만 올린다
24GB 맥이다. 9B(10.4GB) + VL(9.9GB) = 20.3GB 면 Draw Things 가 못 돈다.
글 일 → 9B · 그림 굽기 → 아무것도 안 올림 · 그림 검수 → VL 만.
**Whisper 는 CPU 라 그림 굽기와 같이 돌려도 된다.**

- 발음이 한글인가 → 정규식. 아니면 `vi_kr.word()` 로 다시
- 그림이 겹치나 → 파일 해시

## 13. 낱말이 사는 곳이 **두 군데**다
```
data/days.json    하루 5분 (46일 460낱말, 2026-09-09부터 — 옛 직무 62일은 지움) ← 2권
data/order.json   기본기·문법(grammar.json) / 직무(order.json, 1,106낱말)     ← 1권·3권
```
검수 도구가 `order.json` 만 읽어 **하루 5분 그림 1,080장을 통째로 빠뜨린 적이 있다.**
소리 검수도 같은 구멍이 있었다. **새 도구를 만들면 두 곳을 다 읽는지 확인한다.**

**2026-09-09에 또 걸렸다** — `img_prompt_gen.py`·`gen_word_img.py`가 이번엔
그림 자리에서 **또** `order.json`만 읽고 있었다(일상 314개가 사각지대였다).
세 도구(`img_prompt_gen.py`·`gen_word_img.py`·`img_link.py`)를 전부 고쳐 두 곳을
같이 읽게 합쳤다. **이 경고가 두 번째로 실제로 맞아떨어진 것** — 새 자동화를 짤 때마다
반드시 이 항목부터 확인한다.
